Designed for connected homes

Dual-band connectivity with straightforward network controls

ClearSpan HomeLink R80 is a dual-band Wi-Fi router designed to support up to 64 connected devices.

The router provides separate 2.4 GHz and 5 GHz wireless bands, four Gigabit Ethernet ports and a combined wireless speed of up to 1.8 Gbps.

Integrated parental controls allow the network administrator to create device profiles, pause internet access and configure connection schedules.

Setup guidance

How to connect HomeLink R80

Follow these steps when installing and configuring the router.

  1. 1

    Position the router

    Place the router in an open, central location away from enclosed cabinets and major sources of interference.

  2. 2

    Connect the internet cable

    Connect the modem or internet terminal to the router's WAN port using an Ethernet cable.

  3. 3

    Configure Wi-Fi

    Follow the setup interface to create the network name, password and administrator credentials.

  4. 4

    Add devices

    Connect compatible devices using Wi-Fi or one of the four Gigabit Ethernet ports.

i

Recommended placement

Position HomeLink R80 above floor level and avoid placing it directly beside large metal objects or microwave ovens.

Important information

Safety and Placement

Follow these precautions when installing and operating HomeLink R80.

Installation

Keep the router ventilated

  • Place the router on a stable surface.
  • Do not cover the ventilation openings.
  • Keep the router away from water and high humidity.
  • Use only the supplied power adapter.
Network security

Protect administrator access

  • Change the default administrator password.
  • Use a strong and unique Wi-Fi password.
  • Install available security updates.
  • Disable unused remote-management features.
Notice

Internet service requirements

HomeLink R80 requires an active internet service and a compatible modem or network terminal. Actual speed depends on the service, connected devices and installation environment.
